Opsia / OSC Reference

Every knob, slab and macro in the instrument answers to an OSC address. This is the full /opsia/… namespace — how Pandore, TouchDesigner, or any OSC source plays Opsia, and how Opsia mirrors its state back.

namespace /opsia/… transport UDP values 0 – 1 normalized indices 1-based discovery OSCQuery : port+1
00

Reading the map

one write path, uniform units

Continuous controls take a single normalized float, rescaled to the target's declared range on arrival — so a controller never needs to know a parameter's real min/max. A handful of address shapes cover everything else.

Continuous
One float 0..1, scaled into the declared range of the target.
Enum
An int index, a float 0..1 across the members, or the mode's name string.
Boolean
True at ≥ 0.5 (mute · solo · feedback · isolate).
Trigger
Fires on the rising edge — send 1, then 0 to re-arm.
Color
3–4 raw args r g b [a], or a single value read as grayscale.
Point2D
Two normalized args, each scaled to its own axis range.
Indices
Layers, Meta, Scenes, bands and FX slots all count from 1.
Tempo
/opsia/bpm is the one raw value — sent in BPM, clamped 20..800.

02

Sources & FX racks

slot = A | B · i = 1-based

Each layer has two source slots and three FX racks — one per source, plus the mixed layer rack. Any shader input is addressable by its declared name; the value auto-scales to that input's type and range (including color and point2D multi-arg forms).

AddressArgDoes
…/layer/{n}/source/{slot}sSwap the source generator — shaderId, display name, or none.
…/source/{slot}/{input}f 0..1 →A source shader input, scaled to its range.
…/source/{slot}/fx/{i}/{input}f 0..1 →An input on the per-source FX unit i.
…/layer/{n}/fx/{i}/{input}f 0..1 →An input on the per-layer FX unit i.

Master finishing

always-on chain

Three locked finalizers close every composition — Vibe (palette / colour mastering), Context (atmosphere, depth, PBR relight) and the Finalizer (levels, grain, output shape). Address any of their inputs by name; freely-added master FX use the numbered rack.

AddressArgDoes
/opsia/master/vibe/{input}f 0..1 →A Vibe palette input (colour inputs take 3–4 args).
/opsia/master/context/{input}f 0..1 →A Context input — haze, depth, light (point2D), PBR.
/opsia/master/finalizer/{input}f 0..1 →A Finalizer input — levels, gain, grain, output shape.
/opsia/master/fx/{i}/{input}f 0..1 →An input on a user-added master FX unit i.

The audio brain pushes analysis features straight to the bus, where audio modulators read them per frame. These bypass the parameter store — they're sensor inputs, not controls, and are never echoed back on the feedback stream.

Scenes & Randomize

rising-edge triggers
AddressArgDoes
/opsia/scene/{n}triggerRecall scene n (1-based) — full-instrument state.
/opsia/randomizetriggerRe-roll everything within curated ranges.
/opsia/randomize/{scope}triggerRe-roll one scope — sources · sourceparams · sourcefx · sourcefxonly · layerfxonly · layer · master · finishing · modulators.

/opsia/surface/wayfDraw-path direction : 0 forward · 1 backward · 2 ping-pong.
11

Discovery & feedback

two-way sync

Opsia doesn't just receive — it describes itself and mirrors its live state, so a controller's surface can auto-bind and stay in lock-step as modulators sweep, scenes recall, or a hand moves a slider. Three routes, one shared address space.

OSCQuery · HTTP

The whole parameter tree, self-describing (type · range · value · description). Point a client at the HTTP port to auto-discover every address above.

http://<host>:port+1/ · ?HOST_INFO

OSCQuery · WebSocket

A live value-stream on the same port for web / no-UDP clients. Subscribe per path, receive value frames as controls move.

→ {COMMAND:"LISTEN", DATA:"/opsia/…"}
← {FULL_PATH, VALUE:[v]}

Outbound feedback

A throttled diff-and-send loop pushes only changed controls back to a configured host:port — same /opsia/… addresses, same 0..1. Pandore's UI tracks Opsia's.

Opsia → UDP → host:port
